### 1.2 阶段二写作流水线

- 可复用兼容的阶段一 findings；复用指纹同时校验文件、方案、来源注册表、频次规则版本和 findings
  提示词版本，不兼容时重新提炼。
- 章节规划器按分析重点和 findings 组织章节，不机械照搬 Part；普通章节和核心发现各最多 5 个 block，
  普通低价值 finding 可省略，但风险 finding 与降级 finding 必须覆盖。
- Writer 只接触本次调用内短证据 ID。代码校验 ID、按 finding 回绑代表来源、恢复全局 ID，并在同一
  session/运行命名空间中复用已验证译文；每个 block 最多两条代表反馈。
- 代表反馈的每一行均以 Markdown 引用格式输出，避免多行原话的后续行被误当成报告正文。
- 阶段二只组装前三个固定章节、核心发现、动态分析章节和统计附录；不再调用依赖 `## Part X`
  标题定位的 `inject_qualitative_stats`，因此不会静默丢失逐题客观统计。

### 1.3 三层画像机制

1. **存在性，零额外画像调用**：`profile_presence` 只由代表性 response IDs 计算，语义限定为
   “提及者中包含这些画像”，不表示比例、不排他、不可用于比较。
2. **人群专章，按规划触发**：规划器要求某人群专章时，代码按 `profile_scope = analysis` 的画像值
   筛出该人群全部开放题原文，单独提炼；本轮三个真实方案均未规划人群专章，因此真实运行调用数为 0，
   路径由单元和集成测试覆盖。
3. **差异论断，按需验证**：模型只能提出有限个 `suspected_skew`。代码再对候选做支持玩家验证并在
   内部计算偏离；只有得到 `skewed_toward` 的 finding 才允许 Writer 写“更突出／更集中／尤其明显”。

模型上下文不包含画像比例。观点级画像百分比、比例和精确人数一律拒绝；样本概况中来自确定性 stats
的样本结构数字不受此限制。画像映射或差异验证失败时字段为空、记录原因并继续报告，不放行差异表述。

### 1.4 确定性写作门禁

- 频次表述由 finding 契约和代码插入。模型正文中的“部分玩家”“普遍”“反复提到”“常见情形”
  “往往”等措辞会被中性化；“部分阶段”“大量伤害”等游戏语义不误伤。
- 真实报告人工抽查发现“高度一致”“一致认知”“绝对共识”“被广泛视为”“均提到”“全部分析
  章节反复出现且未见明显分歧”等同义绕过。当前代码已把这些同义表达纳入同一门禁，并完整记录每个
  block 的改写词。
- 画像精确人数门禁只拦截“7 名女性玩家”“女性玩家中有 7 人”等人群计数，不误伤“4 个英雄”
  “2 件装备”或 `Realme C17` 等业务内容。
- 数字、画像差异、证据 ID、必保风险和降级 finding 均在代码侧校验；模型重试耗尽时，确定性降级
  路径仍遵守相同 block 上限、证据绑定和频次中性化规则。

## 5. 风险复核

### 报告质量

- **必然存在**：阶段三语义审校尚未启用。当前门禁能约束证据 ID、频次、数字和画像差异，但不能
  确定性证明每段因果、概括和建议均未曲解原文。
- **本次已发生并已修复**：Writer 用“高度一致／绝对共识”等同义词绕过旧频次词表；当前代码已
  覆盖三份回放中观察到的 11 处新增同义表达。由于这是纯确定性后处理，未重新调用模型；已保存的
  pre-fix markdown 仍保留原样作为证据。
- **符合业务预期，不是隐私风险**：打野报告一条代表反馈包含玩家主动写入的游戏账号标识。该标识
  用于内部问题核对与追溯，数据收集时玩家侧已知晓，报告也只在内部业务范围使用。旧引擎原本就在
  证据表正文第一列展示“玩家 ID”，因此这不是新增暴露面；本次只是同类信息出现在玩家自己写入的
  译文中。后续保留该信息，不新增脱敏规则，同类情况不再作为 NO-GO 或停工确认项。
- **本次已发生、尚未调整**：完整代表反馈造成战备正文偏长。是否截短会影响可核对性，需要在
  “阅读负担”和“原话完整证据”之间另行决策。

### 生成速度与成本

- **特定条件下必然发生**：章节越多、原文越长、Writer 或验证重试越多，调用数、token 与耗时越高。
- 本轮两次新鲜全流程分别为 716.382 秒 / 1,279,273 tokens 和 686.652 秒 / 997,555 tokens；这是真实
  成本证据，但不能外推固定时长。
- suspected skew 上限有效限制了差异验证成本，但也使超出上限的候选直接 unavailable；该行为优先
  保成本可控，不保证覆盖所有潜在人群差异。
- 默认 20 分钟仍只告警不中止；硬超时只在显式试验参数下生效，不会因时间目标作废已完成题目。
