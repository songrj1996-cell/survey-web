# 定性报告快速模式第一版

## 当前范围与使用

本功能为新功能，开发分支 `codex/feature-report-quick-mode`，基线 `34f6722`。
支持普通定性问卷和超过 500 条开放题回答的大样本路径；定量、跑数表、评论、访谈、标注不开放。
`REPORT_QUICK_MODE_ENABLED` 默认 `false`。仅在已隔离的验收进程中开启，不修改真实 `.env`、`data/` 或现有报告。
2026-09-09 用户明确要求直接合入主干，不再额外跑完整报告对照；本次按默认关闭的状态集成。
集成目标以最新核对的本地主干为准，保留同期其他任务的改动；本次不包含推送、部署或正式环境启用。

用户在方案确认页选择完整/快速模式，默认完整；确认请求保存 `pending_report_style`，开始生成后锁定选择。
选择不进入分析方案与指纹，不改变主题提炼、合并、分类、跨题观点筛选的输入与规则。
快速模式按“核心判断 → 关键发现 → 发现与证据附录”展示。前两层默认展开，附录默认折叠。
证据编号打开对应条目，条目顶部可返回该引用处；目录同样能够打开折叠内容并定位。
使用平台现有浅/深色变量、报告目录、版本选择、追问和导出入口。

每份成功版本保存 `report_style` 和独立诊断；旧版本缺失模式时按完整读取。
完整版本的列表摘要保持兼容格式（省略默认模式），快速版本摘要带 `report_style=quick`。
历史读取、追问上下文与导出按所选版本取值。前端折叠及按钮仅作用于 DOM，不改用于导出和追问的 Markdown。
快速版本暂不支持按 Part 局部重做，前后端同时限制；原完整版本的局部重做保持原有判断。

## 写作契约

| 项目 | 约定 |
| --- | --- |
| 输入 | 原有全量分析的逐题 `all_themes`、跨题观点、完整确定性统计、业务背景、分析重点、补充要求 |
| 范围 | 保留题目、Part、筛选人群、频次分母、原始证据和已有来源标识；不重新计算主题频次 |
| 输出 | JSON 协议 v1：title、core、findings、risks、actions；每项 evidence_ids 都必须存在 |
| 正文取舍 | 按决策价值精写，允许不展开所有主题；不设 Top-N；3000–5000 字为软目标，信息少可更短，重要风险多可超出 |
| 附录 | 由程序逐项保留全部目录、统计、主题说明与已有引用；正文未引用的条目标为补充发现与材料 |
| 失败分析输入 | 范围分析失败或降级时追加该范围全部原文，明确不能由此推算观点频次，不采样替代 |
| 空结果 | 无证据时使用明确的数据缺口条目；risks 可以为空，其余组不能为空；不为满足结构编造观点 |
| 成功门槛 | JSON 完整、字段有效、引用存在且不重复；结构通过不等于语义真实性验证 |
| 写作调用 | 计划 1 次逻辑写作，协议错误最多修复 1 次；仍失败不保存成功版本，也不自动切换完整模式 |
| 时间预算 | `LLM_QUICK_REPORT_STAGE_TIMEOUT_SECONDS` 默认 600 秒，首次写作、provider fallback 与一次协议修复共用预算 |
| 最终校验 | 保留既有统计比较句子的确定性校验与最多一次批量修补；该步骤不属于快速写作预算；附录隔离，不参与模型修补或术语替换 |

快速写作使用独立的 `quick_writer_requirements` 提示词，不向模型叠加完整报告的逐章要求。
提示词可在原设置入口管理；目录和输出协议由代码校验，不能通过配置变更取消。
低频财产、安全和可访问性问题不得仅因人数少而被降级。未核实异常仍须标为待核实。
材料不包含研发工作量时不得编造低成本、工期或 ROI 判断；主题人数不得跨主题相加后排名。

## 诊断与失败行为

成功快照的 `quick_report_diagnostics` 记录协议版本、停止原因、阶段预算、逻辑调用数、实际耗时、输入/输出字符数、
目录大小、正文引用与仅附录保留的 ID、未展开比例和写作上游尝试数。
`report_llm_usage` 沿用原有模型、fallback、调用数和 token 记账。
失败写作保存在 session 的 `last_quick_report_failure`，包含 usage；不会替换旧版本的成功诊断。
现有观点诊断按快速协议标识为 `quick_contract_validated`，不再用完整报告的旧式观点标题判断是否漏写。

协议校验不验证每句自然语言是否由引用支持，模型仍可能对原因、优先级或成本产生过度推断。
这类问题需通过内容审阅与同材料回放验收，不能将“有引用编号”视为事实证明。

## 隔离验证

`tests/fixtures/report_pipeline/quick_mode_cases.json` 是完全合成的材料，所有频次、玩家标识与原文均为人工构造。
覆盖正向体验、人群分歧、低频财产风险、弱网问题、可访问性和未在示例正文展开的独立发现。
流程测试分别验证 3 条和 1201 条输入仍全部进入原分析入口；分析与模型在这些测试中使用 mock。

运行前把 `DATA_DIR`、`RESEARCH_ASSET_STORAGE_DIR` 指向批准的隔离目录。
会话存储还有 cwd 相对路径，因此真实服务必须同时隔离工作目录；回放脚本会完成这一步。

```powershell
python -m unittest tests.test_report_quick_mode tests.test_report_quick_mode_flow -q
python scripts/check_boundaries.py
python -m compileall -q app
```

前端浏览器测试 `tests.test_report_quick_mode_frontend` 使用真实 HTML/CSS/JS 与合成接口；
通过 `SURVEY_NODE_PATH`、`SURVEY_PLAYWRIGHT_MODULE`、`SURVEY_BROWSER_PATH` 和可选 `SURVEY_MARKED_FILE` 指定本机已安装工具，不安装新依赖。
`REPORT_QUICK_ACCEPTANCE_DIR` 控制截图输出；缺少运行依赖会明确 skip，不能计为已通过浏览器验收。

```powershell
python scripts/replay_quick_report.py --output <仓库外隔离目录>
python scripts/replay_quick_report.py --output <另一隔离目录> --real --env-file <仅用于读取 LLM 配置的文件>
python scripts/replay_quick_report.py --output <独立预览目录> --serve --port 8767
```

`--real` 明确发起真实模型写作；不带它仅渲染固定示例。env-file 只读取 `LLM_*`，不复制密钥到产物。
`--serve` 仅监听回环地址，在隔离环境历史记录中添加示例；支持通过平台真实页面查看和导出。
该脚本只回放写作与契约，前置分析是预先构造的证据，不能作为真实大样本全链路性能结论。

## 本轮验证与取舍

- 129 项相关后端测试通过，其中包括 15 项快速模式契约、全量输入、失败停止、版本/导出一致性和接口访问测试。
- Chrome 浏览器交互通过，覆盖模式锁定、关闭开关、陈旧请求、证据定位/返回、附录、目录、版本切换、浅/深色与窄屏，零页面脚本错误。
- 合成示例 Word 导出内容检查保留全部 9 项证据与原文；这不是 Word 分页视觉验收。PDF、飞书实机导出和真实模型追问未验收。
- 第一轮真实模型写作使用 claude-sonnet-5，1 次逻辑/上游调用、无 fallback，62.257 秒；发现未经证实的成本判断和对低频可访问性的错误降级，随后收紧提示词。该轮不能作为质量通过证据。
- 第二轮 103.714 秒，成本与低频风险处理有所改善，但仍把引语画像套到了主题人数上；继续约束分群口径与未经验证的原因推断。
- 最终提示词回放：claude-sonnet-5，71.954 秒，1 次逻辑/上游调用，零修复、零 fallback，输入 3526/output 5466 tokens；正文含 Markdown 2920 字符，含完整附录 4928 字符。9 个目录条目均保留，低频风险与人群分歧均被正文引用；已审阅内容。该样本中修正了上述画像归属、低频风险降级和成本断言问题，但比较句的引用范围仍需人工核查，不能据一次结果推断稳定质量。
- 开发期间主干同期发生变化；本次合入需保留这些变更，并在准确的合入后提交上复验。

质量代价：正文选择性展开是必然发生的，读者需要打开附录才能查看未展开发现；
模型可能误选重点或过度推断。程序能保留已识别主题与已有证据，但不能弥补上游未识别出的重要观点。
降级时附录会包含全部原文，阅读与页面渲染负担在该条件下必然增加；Word 的特殊 Markdown 字符沿用既有导出解析限制。

速度代价：不减少上游全量分析，因此上游占用一小时的任务可能仍需很久。
标准路径减少分章写作轮次，大样本原路径本就以单轮写作为主，收益主要取决于输出长度。
完整目录/降级原文可能扩大单轮输入；格式修复与 provider fallback 可能增加调用和耗时，超过总预算会失败。
具体端到端提速幅度证据不足，不能从单次合成写作回放推断。

当前放行边界：用户明确接受跳过额外长报告对照，授权本次默认关闭地合入；该决定不代表真实长报告质量或性能验收通过。
本次仍执行与最新主干共同回归和合入后复验，不增加真实模型报告调用。
真实数量级与题目语义分布的脱敏材料、完整/快速同材料对照及关键风险人工核验仍未完成，正式启用的质量与性能判断继续保留这一限制。
默认关闭开关，正式环境启用、推送、部署或真实数据操作不在本次合入授权内。
