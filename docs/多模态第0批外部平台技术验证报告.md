# 多模态第 0 批：外部平台技术验证报告

## 一、状态说明

本报告记录第 0 批截至 2026-08-12 的验证结果。结论分为：

- **官方契约已确认**：已由官方 REST Discovery 文档和开发者文档确认；
- **脱敏契约样例已覆盖**：已进入本地 fixture 和单元测试；
- **待授权实测**：必须使用非生产账号和非生产问卷完成，不能依据文档推断为已支持。

本报告不代表 Google Forms、倍市得或 Google Drive 生产连接器已经实现。

## 二、Google Forms 官方契约验证

### 2.1 已确认能力

Google Forms API v1 的 `forms.get(formId)` 返回表单内容、设置和元数据。`Form.items` 可包含题目、题组、分页、独立图片、视频和静态文本。

官方资源：

- [Forms REST v1](https://developers.google.com/workspace/forms/api/reference/rest/v1/forms)
- [`forms.get`](https://developers.google.com/workspace/forms/api/reference/rest/v1/forms/get)
- [读取表单和回答](https://developers.google.com/workspace/forms/api/guides/retrieve-forms-responses)

经 REST Discovery revision `20260805` 确认：

| 能力 | 官方字段 | 当前结论 |
|---|---|---|
| 表单稳定 ID | `Form.formId` | 可表达 |
| 内容版本 | `Form.revisionId` | 可作为不透明版本标识；官方只保证返回后 24 小时内有效 |
| 发布状态 | `Form.publishSettings` | 可表达；旧表单可能无此字段 |
| 题目稳定 ID | `Question.questionId` | 可表达 |
| 页面项目 ID | `Item.itemId` | 可表达 |
| 题目图片 | `QuestionItem.image` | 可表达 |
| 题组图片 | `QuestionGroupItem.image` | 可表达 |
| 选项图片 | `Option.image` | 可表达 |
| 独立图片 | `Item.imageItem.image` | 可表达 |
| 视频 | `Item.videoItem` | 可表达 |
| 分页 | `Item.pageBreakItem` | 可表达 |
| 选项跳转 | `Option.goToSectionId` / `goToAction` | 可表达 |
| 矩阵 | `QuestionGroupItem.grid` + `RowQuestion` | 可表达 |
| 文件上传题 | `Question.fileUploadQuestion` | 可读取约束；API 当前不支持创建该题型 |
| 回答与题目关联 | `FormResponse.answers[questionId]` | API 契约可稳定关联 |

### 2.2 图片获取限制

`Image.contentUri` 是可下载图片的输出地址，但官方明确说明它只在有限时间内有效。`Image.sourceUri` 是输入字段，读取时可能为空。

因此未来生产连接器必须：

1. 获取表单后立即下载需保留的图片；
2. 校验重定向、MIME、文件签名、大小和超时；
3. 对内容计算哈希并保存快照身份；
4. 不把 `contentUri` 当作永久素材地址；
5. 不把 OAuth token、临时下载地址或原始敏感内容写入日志。

### 2.3 OAuth 范围

读取问卷定义的最小目标 scope：

```text
https://www.googleapis.com/auth/forms.body.readonly
```

读取回答需单独申请：

```text
https://www.googleapis.com/auth/forms.responses.readonly
```

生产接入应使用 Google OAuth Web Server 流程，按平台用户隔离授权和刷新 token。第 0～1 批不实现 OAuth、token 持久化或回调接口。

官方参考：[OAuth 2.0 Web Server Applications](https://developers.google.com/identity/protocols/oauth2/web-server)

### 2.4 配额

官方当前列出的读取配额为：

- 每项目每分钟 975 次；
- 每用户每项目每分钟 390 次；
- `forms.responses.list` 属于昂贵读取：每项目每分钟 450 次、每用户每项目每分钟 180 次。

生产连接器仍需快照、缓存、指数退避和幂等控制，不能把配额当作无限实时读取。

官方参考：[Google Forms API 使用限制](https://developers.google.com/workspace/forms/api/limits)

## 三、Google Forms 待授权实测矩阵

以下项目尚未用非生产账号完成授权实测，当前不得宣称生产支持：

| 场景 | 需要的样例 | 验证结果 |
|---|---|---|
| 开放问卷读取 | 含题干图、选项图、分页、跳转、矩阵的测试问卷 | 待授权实测 |
| 停止收集后读取 | 与开放问卷相同，随后停止收集 | 待授权实测 |
| 发布链接不可见 | 停止收集且发布页只显示提示 | 待授权实测 |
| 图片下载有效期 | 多次记录 `contentUri` 获取和失效时间 | 待授权实测 |
| 回答题目关联 | 脱敏测试回答 | 待授权实测 |
| 文件上传题资源 | 测试文件上传题和 Drive 文件 | 待授权实测 |
| Workspace 管理策略 | 企业测试账号 | 待管理员策略实测 |

通过条件：实际响应字段与本地 Google fixture 可无损映射；失败场景能区分登录、权限、删除、格式不支持和下载失败。

## 四、倍市得验证状态

### 已有本地事实

- 项目现有 `app/services/questionnaire_import.py` 能解析倍市得原问卷 Excel；
- 原问卷包含题型、题干、选项和矩阵行，可与回答文件确定性匹配；
- 原问卷上传应继续作为稳定保底入口。

### 待外部验证

- 是否存在正式、可授权的生产 API；
- 是否提供稳定问卷、题目和选项 ID；
- 编辑来源是否可稳定返回图片和跳转逻辑；
- 开放和停止收集状态下发布页行为；
- 自动化访问是否符合平台条款和公司安全要求。

未完成上述验证前，连接器决策为 **No-Go**，不能用页面抓取替代正式授权能力。

## 六、第 1 批契约落地

本批代码使用双层模型：

```text
Provider 原始问卷定义
  └─ 保留官方/平台原字段和稳定 ID
      └─ 映射为 CanonicalQuestion
          └─ 通过 AssetReference 绑定 ResearchAsset
```

已覆盖的本地契约能力：

- Google Forms、倍市得、Excel、Drive、YouTube 来源；
- 问卷快照及 Provider/Canonical 双层结构；
- 题目、矩阵、选项、分页和跳转；
- 素材本体与业务引用分离；
- 同一素材多处引用；
- 来源定位、处理状态、访问状态、告警和稳定错误码；
- 内容哈希、去重键和导入幂等键；
- JSON 无损往返和跨对象引用校验；
- 只定义存储端口，不写入或迁移 `data/`。
