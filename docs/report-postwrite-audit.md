## 接入与版本

流程为 Python统计 → 自由写作 → 观点登记 → 原意/人数分批核验 → 保存正文和提示。
每份原回答绑定题目、物理行玩家编号、ref和原文；模型只写释义与支持关系，程序回填原文。

旧版报告沿用旧引擎。新引擎版本的来源、初稿、规则和模型配置绑定检查点。
“继续未完成核验”保留初稿并追加新版本，不覆盖历史版本；达到版本上限时停止追加。
该引擎不支持旧版按章节/题目局部重写。版本查看、追问与导出使用该版本冻结材料。

## 停止与预算

完整流水线默认最多10次实际请求、800000 tokens、45分钟；单次最多8分钟。无自动重试、模型回退或二次审校。

数量任务限定问题与群体；同一批玩家的不同任务共用材料，但每个任务只能使用自己的来源范围。
复杂客观计数口径无法确定时列为未完成并提供Python统计表，不让模型自行补人数。
