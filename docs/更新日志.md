# 平台更新日志

面向使用者的功能更新记录，按部署批次从新到旧排列。纯后端重构、测试补充、内部文档等不影响使用的改动不在此列。

---

## 2026-09-09

**新功能**
- **Google Forms 多语言问卷直读（全新入口，默认关闭）**：配置服务账号后可直接读取 Google Forms 的问卷结构与回答，不再需要导出、拼表、手工对齐题目；支持把同一份问卷的不同语言版本归为"问卷家族"并统一题目映射，多语言回答可绑定进现有定性分析流程，报告证据链保留来源语言与回答引用。入口由管理员在设置页的"Google Link 入口"开关控制，可随时开合、无需重启；上传的文件类回答只保留云端元数据，不读取文件内容
- **个人 LLM Key 与模型用量统计**：启用飞书登录的环境下，模型调用改为使用每位用户在个人中心配置的专属 Key（加密存储），不再共用同一份平台额度；报告页新增模型用量浮层，可查看本次实际使用的模型、备选模型与输入/输出 Token 消耗，用量随报告版本一并保存
- **历史报告局部重做**：不必整份重跑，可只重做指定题目或其所属 Part，原版本完整保留；提交前会再次校验方案与数据指纹，不一致时不会写入新版本。旧报告缺少必要产物时该功能不可用
- **质量结果逐玩家复核与人工改标**：数据标注的质量结果从整张宽表改为玩家列表加逐题档案，可按整体质量、逐题标签、是否人工修改筛选，支持分栏与专注审阅；保留 AI 判断依据，允许人工调整已回答题的最终标签并自动重算整体质量，改动同步进 Excel 下载。最终标签统一为"无效反馈 / 有效反馈 / 优秀反馈"（兼容旧的"普通反馈"），真正空白的题固定为 N/A 并排除在整体计算之外
- **AI 作答确认改为玩家卡片审阅**：待复核玩家按生成概率排序展示，可逐题查看原文与译文及正反证据，支持单人判定、批量判定，并显示复核进度
- **矩阵排名题识别与专用统计**：每行填 1..N 名次的矩阵题不再被当成普通量表处理，改为按名次出统计表（每个子项列出第 1 名到第 N 名的人数与占比），并给出平均名次（数值越低越靠前）。识别采用严格口径，只接受明确的名次表达，任意一行残缺或重复即整体不判定为排名题，避免把普通量表误判
- **整体质量判断升级**：整体质量从"无效是否过半"的单一硬规则改为加权评分（无效/普通/优秀分别计 0/1/2 分），并新增整卷低投入信号识别（评分项全部打同一分、排序题按展示顺序机械填写、主观题全部极短或高度重复等），必须多个信号同时命中才生效，判定理由完整可复核。另针对"是否存在问题；若有请说明"这类条件题单独定了分支规则：明确回答"不存在""没有困难"即视为完成否定分支，不再被误判为无效
- **报告比较结论确定性校验**：报告中"满意度最高""A 高于 B""按均值排序为…"这类比较表述会与原始统计数据逐句硬校验，发现算错或记混排序、名次、并列关系时自动做受限修补
- **报告历史保留上限提高到 40 条**：每位用户最多可保留 40 条报告记录（此前为 20 条）

**性能优化**
- 跨题共同观点归纳改为单次紧凑筛选：此前会串行执行十余次，真实任务曾出现耗时约 46 分钟后仍失败的情况；现改为单次调用并限制整个阶段最多 300 秒，同一批真实候选复测约 153 秒完成
- 报告写作上下文按章节拆分：标题、各 Part、Bug 核查、核心结论、行动建议改为边界清晰的独立上下文，不再在同一消息历史里反复累积全量开放题原文，避免输入 Token 近似平方增长导致长报告后段变慢与质量漂移
- 新增写作阶段逐次调用诊断日志：可区分正常轮次、失败重试、协议回退与备选模型切换，并定位额外等待发生在哪个章节。日志只输出白名单元数据，不记录提示词与回答原文
- 题型识别的容灾备选模型链更新，减少单一模型不可用时的整体失败

**体验优化**
- 报告顶部常驻的统计校验面板收起为工具栏小按钮，按状态显示"通过 / 已修正 / 待确认 / 异常 / 未校验"，详情改为弹窗查看；仅在待确认或校验不完整时保留正文风险提示，并在 Word、PDF、Markdown 与飞书导出前要求确认风险
- 定性报告新增证据边界规则，减少过度解读——例如把问卷没问过的原因当成"不存在"的证据、把出现过的频次误判为最普遍、把"用过某功能"直接推导成体验良好等；核心结论覆盖复核改为对不合格处局部修补，不再整段重写，避免连带丢失原本合规的内容，并且不再要求必须填写业务背景才执行这一步
- 行动建议模块不再固定要求六列表格，可读性更好、飞书等富文本渲染层级更清晰，历史旧格式报告自动兼容转换
- AI 复核页移除顶部"全选 AI / 全部正常"批量按钮，候选卡片列表纵向撑满，卡片编号与玩家详情标题编号改用等宽字体，数字更清晰

**修复**
- **不同账号的会话数据互相隔离**：此前会话接口仅凭任务 ID 读取数据，无法阻止其他账号访问同一会话；现在启用登录后会统一校验会话归属，非所有者一律按"任务不存在"处理。同一账号仍可并行处理多个会话
- 开放题逐条归类时，每批第一条回答可能因回答序号为数字 0 被误判为缺失，导致落入兜底、主题人数与占比被低估
- 定性主题分析取消候选与最终主题的数量上限，主题数量随实际语义确定；低频但与决策相关的观点不再被折叠出报告正文材料，合并过程要求候选一对一完整映射，代表性引用改为从已验证证据确定性还原
- 单批次样本在主题合并阶段调用失败（超时、限流等）时，恢复已经可信的候选主题，不再整题分析失败
- Google Forms 选择题的"其他"开放填写选项不再显示为未命名选项，跨语言与回答绑定过程中保留其语义
- 问卷分析第 3 步回看时能看到已确认的方案内容，不再停留在确认中的加载态
- 统计表格的悬浮态样式不再被通用 Markdown 表格规则覆盖

## 2026-08-26

**性能优化**
- 定性分析（开放题聚类）改为多个题目/模块并行处理，多主题问卷的报告生成更快
- 单次模型调用增加超时保护与自动重试，避免因一次调用挂起导致整份报告生成失败
- 新增主观题观点全流程诊断日志（观点目录生成、聚类状态、写作上下文传递、最终产出是否合规），便于排查报告缺失观点提及等问题，不影响报告生成本身

**体验优化**
- 主观题观点的引用证据改为按回答编号精确匹配原文，不再由模型逐字复制引用文字，避免因引用文字与原文有细微差异导致整批观点被判定无效
- 报告生成、数据标注完成后会展示端到端实际耗时（从确认方案/接受标注开始计算），历史卡片同步显示
- 每个主观题观点后紧跟展示该观点自己的支撑证据表，不再合并成整节末尾的公共引用表，避免证据被挪用到其他观点

**修复**
- 倍市得问卷若题干本身是中文，导入后直接使用原文题干和选项，不再强制经过一次 AI 翻译改写
- 倍市得问卷导入增加更严格的一致性校验（选项/矩阵行编码、题干、联系方式字段识别等），数据不一致时提前报错，避免生成错误统计

## 2026-08-14

**新功能**
- **访谈报告（全新模块）**：上传访谈记录 Excel（一列一位访谈对象，可多 Sheet、可多记录员），系统自动提取关键信息并生成结构化报告，每个模块包含"模块判断 / 主要发现 / 产品建议"三部分；生成后可对审校提醒逐条确认，也可批量勾选多条一次性重新生成
- **倍市得问卷导入更精准**：倍市得原始问卷上传后，题型识别不再依赖 AI 猜测，直接按问卷格式精确解析；专业统计表（跑数表）改为选填，没有也能正常生成定量报告
- **矩阵单选题型支持**：识别、统计、报告写作全流程支持矩阵单选题
- **报告版本历史**：同一份报告可以有多个版本（初版 + 多次重新生成），各版本内容、追问记录互相独立，报告页可切换查看、删除旧版本，导出时也能选择指定版本
- **重复上传智能识别**：再次上传完全相同的问卷数据时会提示"发现重复报告"，可直接查看已有报告，或补充要求后生成新版本，不用重走整个流程
- **分析设置可复用**：同一账号下次上传结构相同的问卷，会提示是否复用上次填写的业务背景和分析思路
- **分析主线**：业务背景表单新增"期望的分析思路"选填项，可引导报告按自定义框架组织内容，而非机械逐题汇总
- **单选题分组成章**：报告可按某道单选题的不同选项分别成章（如按角色/模式分别分析满意度与原因），各章数据严格隔离
- **多语言术语库**：新增术语库管理，可将英雄名、模式名等专有名词的中英文/多语言别名统一为标准中文说法，报告、评论分析、访谈报告均自动应用
- **主观观点可引用精确人数**：核心结论现在可以写"XX名玩家提到了XX观点"这类精确表述（此前只能说"多数/少数玩家"），数字来自确定性统计，同一玩家在多题重复提及不会被重复计数

**体验优化**
- 报告生成等待区改为分步骤展示进度
- 追问前会提示本次依据的原始反馈范围（全部/抽样/无原始数据）
- 提示词管理页全面重构：全屏编辑、支持搜索分组，多人同时编辑会提示冲突不会互相覆盖
- 权限管理页改为按功能模块卡片式展示

**修复**
- 修复标注模式下点击"重新开始"误触发问卷会话重置的问题
- 修复方案修订时 AI 可能编造不存在的交叉分析维度的问题
- 优化数据标注质量判断提示词，更准确区分"无实质内容的评价"和有效反馈

## 2026-07-20

**新功能**
- **可选业务背景与行动建议**：题型确认页新增可选填写"想解决什么问题/背景/目标用户/最关心的问题/报告用途"，报告据此生成针对性的行动建议模块（放在报告末尾）
- **选择题"其他"填空识别**：单选/多选题中实际是自由文本填空的选项会被自动识别为"其他"，其内容纳入开放题分析，题型确认页可查看示例并手动启用/禁用
- **矩阵题子项支持内联编辑**：题型确认页可直接修改矩阵题子项名称
- **问卷分支跳转推断**：自动识别问卷内的分支跳转关系，报告写作时不同分支的回答不会被错误混用或错误合并计算
- **飞书导出高亮块**：核心结论在导出的飞书文档中显示为高亮框，而非普通段落

**体验优化**
- 定性报告章节内容改为按业务主题综合叙述，不再逐题罗列；玩家身份信息统一为"玩家ID / 画像信息 / 中文翻译"三列展示，反馈原文统一显示中文翻译
- 数据标注模块整体重构：识别更准确（AI概率+润色概率双指标）、支持只重跑缺失/失败的行、新增独立翻译修复环节
- 报告追问上下文改为完整持久化保存，服务重启或长时间未操作也不会丢失追问历史
- 定性报告写作改为直连大模型服务，报告生成响应更稳定

**修复**
- 修复 Google 表单中"其他"选项的自由填空内容被误判为标准选项，导致选项统计出现异常数值的问题
- 上传文件不再支持旧版 .xls 格式，仅支持 .csv/.xlsx；上传后锁定文件，避免流程中途误换文件

## 2026-06-25

**新功能**
- **评论分析模块（全新上线）**：上传帖子评论文件（CSV/Excel），自动做相关性筛选，只分析与主题相关的评论，并从长评论中精选最多 50 条代表性原文译成中文附在报告末尾；新增"评论分析"独立权限
- 新增管理员审计日志页面，可查看关键操作记录
- 数据标注结果纳入历史记录，历史卡片可直接下载标注结果

**体验优化**
- 大样本问卷（倍市得跑数表模式）支持直接复用用研已产出的统计表，平台不再重复计算数字，只做主观题聚类分析
- 历史记录上限从 5 条提升到 20 条，历史抽屉改为双列卡片展示，支持按报告类型/生成时间筛选
- 数据持久化改进：服务重启、多进程部署不再导致会话丢失或历史记录异常

## 2026-06-15

**新功能**
- 倍市得跑数表模式流程简化：跳过题型确认环节，上传后直达方案确认，4 步即可出报告
- 报告写作新增"满意度优先"规则：若数据中存在满意度相关统计，会优先展示在核心结论最前面
- 受访者画像固定展示在报告第一部分

**修复**
- 修复大样本模式误判：调整阈值判断逻辑，避免小样本问卷被错误当成大样本处理
- 修复数据标注偶发漏返行的问题，新增自动重试与缺失提示，避免下载到不完整的标注结果
- 修复飞书文档导出失败的问题（权限配置调整）
- 修复流式生成报告时出现 `**` 符号未正确加粗显示的问题
- 优化选项别名（alias）管理界面，支持逐条添加/删除，避免误合并不同选项
