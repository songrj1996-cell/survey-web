# 访谈报告 V2：V1 输入文件要求

> 合同版本：`interview-file-contract/1.0-draft`
> 状态：批次 1 物理文件合同已冻结；结构语义阈值仍需研究员用更多真实样本确认。

## 上传前请确认

- 一次只上传一个 `.xlsx` 文件。
- 同一个 Excel 只记录同一份基础访谈提纲；访谈期间临时增加、调整或停止询问的问题可以保留。
- 每个记录 Sheet 中，一列只能对应一名玩家，同一玩家列正文不得混写其他玩家。
- 同组的多个记录 Sheet 应记录同一批玩家；不同组的 Sheet 应记录不同玩家。
- 建议在 Sheet 名中标明组别和记录员，例如“1组记录1”“1组记录2”“2组记录”。
- 同组不同 Sheet 中，同一玩家建议使用相同列名；列顺序相同不能单独作为自动合并依据。
- 功能模块、主问题和行类型至少需要能从列、标题、排版或明确上下文之一识别。
- 空白预留追问行可以保留，不会自动视为漏问。
- 问题栏为空但玩家格有内容时，系统会保留内容并要求按上下文确认其身份和归属。
- 文件不得设置打开密码，也不能依赖宏或外部链接取得主要内容。

平台从访谈结束后的记录整理开始，不创建访谈提纲、记录模板，也不管理招募、排期、翻译或访谈执行。

## 同组与异组示例

```text
1组记录1 + 1组记录2
→ 可以提出“同组多记录员”建议，但必须由上传者确认后才合并玩家。

2组记录
→ 属于另一批玩家；即使列名同为 P01，也不能与 1组-P01 自动合并。
```

## 物理合同与语义责任

系统负责检测可观察的物理违约，例如：

- 文件类型、损坏、加密和系统上限；
- 玩家候选列缺失、列头重复或一列无法稳定绑定一个候选玩家；
- 无法形成“模块—主问题—玩家内容”的最低结构；
- Sheet、行、列或单元格坐标无法稳定读取。

上传者负责确认系统无法完全证明的语义事实，例如：

- 一列正文是否混入另一名玩家；
- 多张 Sheet 是否属于同一访谈组；
- 同组不同记录员的玩家列是否代表同一玩家；
- 临时问题、借位记录和无问题文本的内容归属。

## 兼容边界

V1 可以接受：

- 多个访谈组和同组多记录员；
- Sheet 名不标准，但仍能提出候选并由用户确认；
- 空白预留行、合并单元格、少量隐藏行列；
- 底部临时新增问题、不同记录员使用不同追问；
- 少量非中文玩家原话，原文必须保留。

V1 阻断：

- 不是 `.xlsx`、文件加密、损坏或超过已配置上限；
- 无法确认一列对应一名玩家；
- 同一文件混入多份无关提纲且无法拆分；
- 无法形成最低结构；
- 主要内容必须执行宏、读取外部链接或解析不受支持的媒介才能取得。

## 批次 1 确定性安全预检

本功能仅供团队内部使用，批次 1 不接入独立病毒扫描服务，也不返回“未配置病毒扫描”之类的告警。上传仍必须通过以下确定性检查：

- 扩展名和内容都必须是有效的 `.xlsx` OOXML/ZIP；伪装扩展名、损坏文件和加密文件直接拒绝；
- 包含宏内容或外部链接的工作簿直接拒绝；
- 公式只作为物理事实保留，不执行公式、宏或外部内容；
- ZIP 条目数、解压后体积和压缩比必须在固定上限内；
- Sheet、行列、物理单元格、合并覆盖面积、超链接或评论可能展开出的单元格、非空单元格和文本总量必须在固定上限内；
- 样式表、共享字符串、关系、条件格式、评论和绘图等会被 Excel 解析器全量加载或物化的 OOXML 部件另有更严格的内部安全限额；
- 至少一张工作表必须能提出左侧结构区和候选玩家区，否则作为不满足最低访谈结构拒绝；候选结果仍需人工确认。

批次 1 默认上限如下，部署时只允许通过环境变量收紧或调整，不得在请求中绕过：

| 项目 | 默认上限 |
|---|---:|
| 单文件大小 | 50 MB |
| ZIP 条目数 | 5,000 |
| ZIP 解压后总大小 | 250 MB |
| 单条目压缩比 | 100 |
| Sheet 数 | 64 |
| 单 Sheet 行数 | 5,000 |
| 单 Sheet 列数 | 256 |
| 全工作簿物理/非空单元格数及合并覆盖面积 | 各 250,000 |
| 全工作簿文本字符数 | 5,000,000 |

拒绝的上传会立即删除隔离区中的原始文件，只保留不含玩家原文的错误元数据。通过预检的原文件和物理快照会分别保存；正式启用前仍需冻结已接受文件及派生物的保留周期。

## 空白和覆盖口径

空白只表示“当前单元格没有记录”，不得自动改写为“没有意见”“没有需求”“未询问”或“不适用”。覆盖状态必须分别记录：

- 源提纲是否存在该问题；
- 是否确认询问；
- 是否确认适用；
- 玩家自述、追问补充和研究员观察分别有什么证据；
- 当前判断是否已复核或被排除。

只有问题存在、确认已问且确认适用的独立玩家才能进入比例分母。

## 后续批次仍待冻结的参数

- 单项目最大玩家数；
- Sheet 分组、玩家绑定及结构识别的默认勾选阈值；
- 无可靠父问题的追问或观察是阻断还是带警告继续；
- 大段非中文内容的能力提示和降级规则；
- 已接受原文件、中间证据、模型输入输出和导出物的保留周期。
