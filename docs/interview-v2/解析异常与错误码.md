# 访谈报告 V2：解析异常与稳定错误码

> 状态：持续更新至批次 5A。错误码属于接口合同，不得用模型自由文本替代；当前不定义病毒扫描告警。

## 分类

- `blocking`：不能创建正式项目或不能进入下一阶段。
- `confirmation_required`：保留已完成物理解析，但必须人工确认。
- `warning`：允许继续，且不得把不确定内容用于正式报告主张。
- `partial_failure`：保留成功单元，只重试失败范围。

| `UPLOAD_REQUEST_INVALID` | blocking | 检查 multipart 字段并重新选择文件 |
| `RESEARCH_FOCUS_TOO_LONG` | blocking | 将报告重点缩短到 4,000 字符以内 |
| `FILE_EMPTY` | blocking | 重新选择包含内容的文件；仅用于解析器直接调用 |
| `FILE_CONTRACT_NOT_ACKNOWLEDGED` | blocking | 阅读并勾选当前文件合同 |
| `FILE_CONTRACT_VERSION_MISMATCH` | blocking | 刷新页面并按当前合同重新确认 |
| `WORKBOOK_ENCRYPTED` | blocking | 移除打开密码后重新上传 |
| `WORKBOOK_CORRUPTED` | blocking | 使用 Excel 修复或另存后重试 |
| `WORKBOOK_LIMIT_EXCEEDED` | blocking | 按提示拆分或精简文件 |
| `WORKBOOK_MACROS_UNSUPPORTED` | blocking | 移除宏内容并另存为普通 `.xlsx` |
| `WORKBOOK_DEPENDS_ON_EXTERNAL_CONTENT` | blocking | 将主要内容固化到工作簿内 |

|---|---|---|
| `SHEET_ROLE_AMBIGUOUS` | confirmation_required | 标记记录 Sheet 或忽略页 |
| `GROUP_MAPPING_CONFIRMATION_REQUIRED` | confirmation_required | 确认同组、异组和记录员 |
| `PARTICIPANT_COLUMN_MISSING` | blocking | 指定或修正玩家列 |
| `PARTICIPANT_COLUMN_DUPLICATE` | confirmation_required | 为重复列头建立明确玩家绑定 |
| `PARTICIPANT_MAPPING_AMBIGUOUS` | confirmation_required | 确认同组不同 Sheet 的玩家对应关系 |
| `PARTICIPANT_MAPPING_CONFIRMATION_REQUIRED` | confirmation_required | 确认候选玩家列及同组玩家对应关系 |

## 统一错误体要求

V2 路由和 service 自身产生的业务错误至少返回：

```json
{
  "error": {
    "code": "PARTICIPANT_MAPPING_AMBIGUOUS",
    "message": "同组玩家列无法可靠对应，请确认玩家关系。",
    "retryable": false,
    "suggested_action": "open_group_mapping",
    "context": {},
    "trace_id": "trace_01"
  }
}
```

`context` 只包含定位所需 ID、Sheet/列坐标和计数，不记录玩家原文。

平台统一登录/权限中间件仍沿用现有 HTTP 错误语义，不属于本文件的 V2 业务错误体。部署配置为 `INTERVIEW_V2_ENABLED=false` 时，`app/main.py` 不注册 V2 路由，对外表现为端点不存在；`INTERVIEW_V2_DISABLED` 仅是路由被独立挂载时的防御性保护。
